# Data Science Projects Repository

This repository contains multiple data science projects covering exploratory data analysis (EDA), regression models, and deep learning approaches. Each project explores different datasets and analytical techniques.

#Projects

1. NYC Airbnb 2019 - Exploratory Data Analysis

- Utilizes Pandas and NumPy for data exploration

- Analyzes trends and insights from the NYC Airbnb dataset

- Visualizes key metrics related to Airbnb listings

#2. Weather and Energy Data - Regression Models

- Performs EDA on weather and energy consumption data

- Implements logistic and linear regression models

- Investigates relationships between weather patterns and energy usage

3. Stock Price Prediction - Deep Learning & Traditional Approaches

- Implements a Long Short-Term Memory (LSTM) neural network for stock price forecasting

- Compares LSTM performance with traditional statistical methods

- Explores feature engineering techniques for time series data
